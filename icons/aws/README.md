# Íconos de AWS

Íconos oficiales **AWS Architecture Icons** (versión 01/30/2026) de Amazon Web Services:
https://aws.amazon.com/architecture/icons/

Se tomaron del paquete npm [`aws-icons`](https://www.npmjs.com/package/aws-icons) (licencia MIT, ver `LICENSE-aws-icons-package.txt`) y se renombraron según el id de cada servicio en la web (`lambda.svg`, `apigw.svg`, …). Los archivos `u-*.svg` son íconos genéricos (usuario, móvil, servidor…) y `z-*.svg` los de grupos (AWS Cloud, VPC, subnets, datacenter).

AWS permite usar estos íconos para crear diagramas de arquitectura. Amazon Web Services y los nombres de sus servicios son marcas de Amazon.com, Inc. o sus afiliadas.
